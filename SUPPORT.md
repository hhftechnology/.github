# Getting help with HHF Technology projects

**The [HHF forum](https://forum.hhf.technology) is the home for questions, help and discussion** about every hhftechnology project. Each project has its own category there, and GitHub issues for the project are copied into it automatically, so you can discuss them on the forum.

| I want to… | Go to |
|---|---|
| Ask how to set something up, or get help with an error | [Forum: Help](https://forum.hhf.technology/c/help/85), or your project's category |
| Suggest a feature or share an idea | Your project's category on the forum, tagged `feature-request` |
| Report a reproducible bug | **New issue** on the project's GitHub repo (use the bug template) |
| Chat with the community | [Discord](https://discord.gg/HDCt9MjyMJ) |
| Report a security vulnerability | **Not in public.** See [SECURITY.md](https://github.com/hhftechnology/.github/blob/main/SECURITY.md) |

Project categories:
- [Traefik Plugins & Tools](https://forum.hhf.technology/c/traefik-plugins-tools)
- [Pangolin & Newt Tools](https://forum.hhf.technology/c/pangolin-newt-tools)
- [Docker & Deploy Tools](https://forum.hhf.technology/c/docker-deploy-tools)

When you ask, include the project version, your config (with secrets removed), logs, and what you already tried.
